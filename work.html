Work

Pomodoro goal timer: set a daily goal of real work minutes, then the timer runs in work stretches (everything is blocked — pure focus; these are the minutes that count toward your goal) and rest stretches (the block is off — take a real break; these don't count). When a work stretch is done a chime plays and the break starts automatically. When the break is over, another chime rings — and keeps ringing — until you start the next work stretch (or pause it to be quiet): work never starts by itself. Hit the goal and the day is done; a day that ends short of the goal is just logged — the timer is never locked.
